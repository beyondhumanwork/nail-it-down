# Community code of conduct

We want Nail It Down to be a constructive open-source project.

Contributors and maintainers are expected to be respectful, assume good faith, and focus criticism on ideas and observable behavior rather than individuals. Harassment, discrimination, threats, doxxing, and abusive language are not acceptable.

Maintainers may edit or remove harmful content, close conversations, and limit participation when necessary to protect community members.

To report conduct concerns, use a GitHub issue **only if the report contains no private or sensitive information**. For sensitive issues, request private contact through the repository maintainers rather than publishing personal details.

This short policy is project-authored; it is not presented as an adoption of another organization's code-of-conduct text.
